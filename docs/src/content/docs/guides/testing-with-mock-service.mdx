---
title: Testing with a mock service
description: Write tests without hitting the real postcodes.io API.
---

Because `PostcodesClient` is a `Context.Service`, you can replace the entire
implementation with a test double using `Layer.succeed`. No HTTP mocking library
or network interception needed.

## Basic test double

```typescript
import { Effect, Layer } from "effect"
import { PostcodesClient, type PostcodeResult } from "@effect-postcodes/client"

const mockResult = {
  postcode: "SW1A 1AA",
  country: "England",
  region: "London",
  // fill in the fields your code under test actually reads
} as PostcodeResult

const unexpectedMethod = (method: string) =>
  Effect.die(new Error(`Unexpected mock call: ${method}`))

const MockClient = Layer.succeed(PostcodesClient, {
  lookupPostcode: (_postcode) => Effect.succeed(mockResult),
  bulkLookupPostcodes: (_postcodes) => unexpectedMethod("bulkLookupPostcodes"),
  findOutcode: (_outcode) => unexpectedMethod("findOutcode"),
  findPlace: (_code) => unexpectedMethod("findPlace"),
  randomPostcode: () => unexpectedMethod("randomPostcode"),
  searchPostcodes: (_search) => unexpectedMethod("searchPostcodes"),
  findNearestPostcodes: (_postcode) => unexpectedMethod("findNearestPostcodes"),
  searchPlaces: (_query) => unexpectedMethod("searchPlaces"),
  randomPlace: () => unexpectedMethod("randomPlace"),
  lookupTerminatedPostcode: (_postcode) => unexpectedMethod("lookupTerminatedPostcode"),
  lookupScottishPostcode: (_postcode) => unexpectedMethod("lookupScottishPostcode"),
})

// In your test (example uses bun:test):
import { expect, test } from "bun:test"

test("looks up a postcode", async () => {
  const result = await Effect.runPromise(
    Effect.gen(function*() {
      const { lookupPostcode } = yield* PostcodesClient
      return yield* lookupPostcode("SW1A1AA")
    }).pipe(Effect.provide(MockClient))
  )
  expect(result.postcode).toBe("SW1A 1AA")
})
```

## Testing 404 paths

```typescript
import { ApiNotFoundError } from "@effect-postcodes/client"

const NotFoundClient = Layer.succeed(PostcodesClient, {
  lookupPostcode: (postcode) =>
    Effect.fail(ApiNotFoundError(
      "postcode",
      postcode,
      { status: 404, error: "Postcode not found" }
    )),
  bulkLookupPostcodes: (_) => unexpectedMethod("bulkLookupPostcodes"),
  findOutcode: (_) => unexpectedMethod("findOutcode"),
  findPlace: (_) => unexpectedMethod("findPlace"),
  randomPostcode: () => unexpectedMethod("randomPostcode"),
  searchPostcodes: (_) => unexpectedMethod("searchPostcodes"),
  findNearestPostcodes: (_) => unexpectedMethod("findNearestPostcodes"),
  searchPlaces: (_) => unexpectedMethod("searchPlaces"),
  randomPlace: () => unexpectedMethod("randomPlace"),
  lookupTerminatedPostcode: (_) => unexpectedMethod("lookupTerminatedPostcode"),
  lookupScottishPostcode: (_) => unexpectedMethod("lookupScottishPostcode"),
})
```

## Why the complete interface matters

`Layer.succeed(PostcodesClient, ...)` replaces the complete public service, so a
mock must provide all eleven methods. The `unexpectedMethod` helper converts an
unexpected call into a defect rather than silently returning an undefined value.
Keep the result fixture as small as the code under test allows, but type it as
the exported runtime result type so the mock's expected success value remains
explicit.
