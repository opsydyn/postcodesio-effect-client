`@effect-postcodes/client` is the production Effect-native client for
[postcodes.io](https://postcodes.io). It provides one stable `PostcodesClient`
service for the complete postcode and place endpoint surface; generated OpenAPI
transport stays internal.

```bash
npm install @effect-postcodes/client effect
```

The service supports postcode lookup, text-or-coordinate postcode search,
1–100-item bulk lookup, nearest and random postcodes, terminated and Scottish
postcode lookup, outcode lookup, and place search, lookup, and random place.

`searchPostcodes` accepts either `{ query }` or a complete
`{ latitude, longitude }` pair. Invalid mixed/incomplete searches and invalid
bulk sizes fail with the exported `ApiValidationError`; not-found resources use
`ApiNotFoundError`. All methods otherwise expose Effect HTTP, schema, and rate
limiter failures through `ApiServiceError`.

The package exports runtime schemas and inferred types for postcode, bulk,
nearest, terminated, Scottish, outcode, and place results. Import those and the
service from `@effect-postcodes/client`, never from the generated transport.

Northern Irish postcodes.
