## `PostcodesClient`

`PostcodesClient` is a `Context.Service` covering the supported
postcodes.io postcode and place operations. Every method returns
`Effect<Success, ApiServiceError>`.

| Method | Parameters | Returns |
| --- | --- | --- |
| `lookupPostcode` | `postcode: string` | `PostcodeResult` |
| `searchPostcodes` | `search: PostcodeSearch` | `readonly PostcodeResult[]` |
| `bulkLookupPostcodes` | `postcodes: readonly string[]` | `readonly BulkLookupItem[]` |
| `findNearestPostcodes` | `postcode: string` | `readonly NearestPostcode[]` |
| `randomPostcode` | none | `PostcodeResult` |
| `lookupTerminatedPostcode` | `postcode: string` | `TerminatedPostcode` |
| `lookupScottishPostcode` | `postcode: string` | `ScottishPostcode` |
| `findOutcode` | `outcode: string` | `OutcodeResult` |
| `searchPlaces` | `query: string` | `readonly PlaceResult[]` |
| `findPlace` | `code: string` (OS Open Names ID) | `PlaceResult` |
| `randomPlace` | none | `PlaceResult` |

`PostcodeSearch` has two valid shapes:

```ts
{ query: "SW1A" }
{ latitude: 51.501, longitude: -0.142 }
```

Do not mix the modes or omit one coordinate. Bulk lookup accepts 1–100
postcodes. Those validation failures return `ApiValidationError` before a
request is made.

### Static members

| Member | Type | Description |
| --- | --- | --- |
| `.Default` | `Layer<PostcodesClient>` | Fetch HTTP client and in-memory rate limiter. |
| `.layer(config?)` | `Layer<PostcodesClient, never, HttpClient>` | Requires a caller-provided HTTP client. |
| `.make(config?)` | `Effect<PostcodesClient.Service>` | Direct service construction for scripts and top-level programs. |

## Runtime schemas and types

Import the public schemas and inferred types from `@effect-postcodes/client`:

- `PostcodeResult`
- `BulkLookupItem`
- `NearestPostcode`
- `TerminatedPostcode`
- `ScottishPostcode`
- `OutcodeResult`
- `PlaceResult`

`BulkLookupItem.result` is `null` when a requested postcode is unknown. Do not
import the generated transport schemas: they are implementation artefacts and
may change on regeneration.
